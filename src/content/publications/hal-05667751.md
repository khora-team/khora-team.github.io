Large Language Models (LLMs) are increasingly used for code generation, motivating the development of benchmarks assessing the security of generated code. However, most existing benchmarks evaluate each task using a single prompt template or a limited set of prompt variations, providing only a partial view of model behavior.Since the security of generated code may strongly depend on how a task is formulated, such evaluations can overlook important variations in model performance. This poster presents the ongoing development of a benchmark designed to systematically explore the prompt space of security-sensitive programming tasks.Rather than providing a binary assessment of whether a model generates secure code, our objective is to characterize how security outcomes evolve across different prompt formulations. By capturing this variability, we aim to provide a more detailed understanding of the conditions under which LLMs are more likely to generate secure or vulnerable code.
